# Wideband-FM-Multipath-Interference-Capture-SDRv3

An experimental study of wideband FM multipath using an RTL-SDR Blog V3 and a V-shaped dipole. It documents a 7 dB SNR enhancement lasting ~2 seconds, a coherent two-ray interference event from a moving aircraft crossing the signal path between Gongala FM transmitter and a receiver in Malabe, Sri Lanka. The noise floor remained unchanged, confirming coherent signal addition rather than incoherent interference.
